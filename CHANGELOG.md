# История изменений

Формат — по версиям приложения (`APP_VERSION` в `app/config.py`). Даты локальные.

## 0.7 — текущая

**Интерфейс**

- Русский и английский интерфейс: переключатель в настройках, перерисовка сразу,
  выбор сохраняется и применяется при следующей загрузке.
- Перевод покрывает навигацию, карточки проекта, формы агентов и задач, настройки,
  историю, шаблоны, роли, инструменты и системные сообщения; исходные тексты
  запоминаются, поэтому возврат к русскому восстанавливает всё без потерь.

**Документация**

- Английская версия README (`README.en.md`) и полный набор документов в `docs/en/`:
  руководство, архитектура, API, безопасность, тесты, частые ошибки.

- Проводник рабочей области: для папки вне разрешённых корней появилась кнопка
  «Разрешить эту папку» — больше не нужно вручную править настройки, чтобы выбрать другой диск.

- Флаг «Запрос подтверждения у человека» отключён в интерфейсе: CrewAI поддерживает его только в консоли, а в GUI запуск зависал на `input()`. Старые проекты с этим флагом запускаются, флаг игнорируется с предупреждением.

- Проводник проверяет права на чтение и запись при открытии папки: папку только для чтения нельзя выбрать, сервер отклоняет её как рабочую область с понятным сообщением.

- Редактор шаблонов: шаблон открывается в конструкторе, агенты и задачи добавляются сразу; есть «Пустой шаблон»; при применении проект создаётся уже заполненным.

- Авторизация: страница входа, регистрация, сессии в cookie, первый администратор admin/123admin! и смена пароля в настройках; API закрыт без сессии.

- Время жизни сессии настраивается (по умолчанию 12 часов), после первого входа с паролем по умолчанию приложение требует сменить пароль, пока он не сменён — API и страницы закрыты.

- Документация: новые разделы [auth.md](docs/auth.md) и [logging.md](docs/logging.md); API описан с авторизацией, в руководстве и troubleshooting — смена пароля, восстановление доступа и поиск ошибки по `error_id`.

- Ограничение попыток входа (5 за 10 минут), сброс остальных сессий при смене пароля, кнопка «Выйти везде»; Enter отправляет формы входа и смены пароля; авто-перезагрузка при смене токена.
- `crewai` закреплён на 1.15.45, `start.bat` предпочитает Python 3.12; в `docs/testing.md` добавлены `test_auth.py` и `test_human_flag.py`.

- Рефакторинг структуры: REST-обработчики вынесены в `app/api/dispatch.py`, фронтенд разнесён на `web/js/{core,builder,run,pages,handlers,app}.js`; поведение не менялось.

- Пагинация истории запусков (50 на страницу, фильтр по статусу) и retention: срок хранения настраивается (30/90/180 дней, год, всегда), старые запуски удаляются при старте, максимум 5000 записей.

- Экспорт/импорт проектов (`project-<id>.json`) и ZIP-бэкап данных без логов и сессий; у аккаунтов убраны роли admin/user — все равноправны.

**Репозиторий**

- Из репозитория убраны служебные файлы процесса разработки; публикуется только
  приложение, тесты и документация.
- Добавлен браузерный тест переключения языка (`tests/test_ui_i18n.py`).

## 0.6

**Запуск и надёжность**

- Необъявленные фигурные скобки в тексте задачи больше не роняют запуск: они
  остаются текстом, объявленные поля подставляются.
- Параметры запуска (итерации, лимит времени, рассуждения, память, инструменты)
  печатаются в журнал первой строкой.
- Память без ключа эмбеддингов отключается с предупреждением.
- Отмена: `cancelling` → `force_stopping` через 12 с, слот освобождает только
  завершение потока; «Отсоединить» освобождает слот немедленно.
- Отсоединённый прогон не пишет файлы, не ходит в сеть и не получает ответов на
  подтверждения.
- Прерванные запуски помечаются при старте, а не висят в «выполняется».

**Безопасность**

- Периметр: `Host`/`Origin`, токен сессии, `application/json`, лимит тела,
  отказ от chunked, CSP и заголовки безопасности, только loopback.
- Статика только из `web/`; девять вариантов обхода пути отклоняются.
- Рабочая область проверяется при сохранении **и** при запуске; служебные
  каталоги запрещены по resolved-пути.
- `output_file` — только имя файла; inline-спека отклоняется; частичный `PUT`
  проекта отклоняется.
- Сторонние файловые и RAG-инструменты удалены; сетевые — поимённый opt-in,
  подтверждение выхода в сеть, проверка URL-аргументов, событие `tool_network`.
- `fetch_url`: SSRF-политика, редиректы с повторной проверкой, таймаут и лимит
  чтения.
- Переменные окружения — allow-list; ключи шифруются; логи и снимки запусков
  редактируют секреты.
- `/api/crews/{id}/code` валидирует проект перед генерацией.

**Хранение**

- `data/runs/index.jsonl` с компакцией, кольцевой буфер событий, чекпойнты,
  карантин повреждённых проектов.
- SSE с `id:` и возобновлением по `Last-Event-ID`.

**Интерфейс**

- Роли: 12 встроенных, включая «Старшего системного архитектора» с процессом из
  четырёх этапов и контрактом вывода.
- Шаблоны: свои, с переименованием и удалением; рабочая область в шаблон не
  переносится.
- Проводник рабочей области с разрешёнными корнями и созданием папок.
- Окно подтверждения показывает, что именно открывается: файл или папка.
- Кнопка «Отсоединить» для зависших запусков.
- Исправлена гонка автосохранения, из-за которой сброс рабочей области мог
  откатиться.
