# Безопасность

Приложение локальное, но работает с двумя чувствительными вещами: файлами на диске
и API-ключами провайдеров. Этот документ описывает модель доверия, что уже закрыто
и какие риски остаются.

## Модель доверия

| Субъект | Доверие |
|---|---|
| Пользователь за этим компьютером | полное: он владеет папкой `data` и настройками |
| Браузерная страница Studio | доверенная, но получает токен сессии из HTML |
| Другая вкладка/сайт в том же браузере | **не доверяется** |
| Модель и её ответы | **не доверяется**: текст модели — данные, не команды |
| Содержимое файлов и веб-страниц | **не доверяется** |
| Сторонние инструменты `crewai-tools` | **не доверяется**: их код неподконтролен |

Главный принцип: любой путь, приходящий из запроса, проекта, шаблона, скопированной
папки `data` или аргумента инструмента, проходит через политику; любой инструмент,
работающий с файлами или сетью, создаётся только через обёртку.

## Что закрыто

### Периметр HTTP

- Сервер слушает только `127.0.0.1`; запуск на другом адресе запрещён.
- Проверка `Host` и `Origin` — защита от DNS-rebinding.
- Токен сессии (`hmac.compare_digest`) на все изменяющие запросы — защита от CSRF.
- Только `application/json` с `Content-Length`; chunked отклоняется.
- CORS-заголовков нет: чужая страница не прочитает ответы.
- `nosniff`, `Referrer-Policy`, `X-Frame-Options`, CSP для HTML.
- Таймаут сокета 20 с и семафор на 64 соединения — защита от slowloris.
- Тело запроса ограничено 64 МБ.

### Файловая система

- Статика отдаётся только из `web/`: `..`, `\`, NUL, диски и абсолютные пути
  отклоняются (проверено тестами на девяти вариантах обхода).
- Рабочая область проверяется и при сохранении проекта, и при запуске: проект,
  принесённый копией `data/` со служебной папкой, откатывается на папку по
  умолчанию с предупреждением.
- Служебные каталоги (`Windows\System32`, `Startup`, `.ssh`, `site-packages`,
  `node_modules`, `app`, `web`, `data\crews`, `data\runs`) запрещены — по
  **resolved** пути, поэтому симлинк или джанкшен не помогает.
- Результат задачи (`output_file`) принимается только как имя файла и всегда
  пишется в рабочую область.
- Инструменты ограничены рабочей областью; выход за неё требует подтверждения,
  а служебные каталоги отклоняются без диалога.

### Сеть

- `fetch_url`: запрещены private, loopback, link-local, reserved и multicast
  адреса; до трёх редиректов с повторной проверкой каждого; таймаут 20 с; чтение
  не больше 1,5 МБ.
- Сторонние сетевые инструменты выключены по умолчанию и включаются поимённо;
  каждый вызов проверяет URL-аргументы, спрашивает разрешение и попадает в журнал
  событием `tool_network`.
- `file://`, `ftp://` и прочие схемы отклоняются.

### Данные

- API-ключи шифруются: Windows DPAPI (привязка к учётной записи) или Fernet с
  локальным ключом `data/.secret.key` (права 0600).
- В браузер уходят только маски и флаги «ключ сохранён».
- Логи редактируют `sk-…`, `Bearer …` и `api_key=…`; срок хранения — 30 дней.
- Сохранённые запуски тоже проходят редакцию ошибок и итогового текста.
- Переменные окружения принимаются по allow-list: `*_API_KEY`, `*_BASE_URL`,
  `STUDIO_*`. `PATH`, `PYTHONPATH`, `LD_*`, `SSL_*`, `PIP_*` и подобные
  отклоняются.

### Запуск

- Одновременно выполняется один прогон: event bus CrewAI глобальный.
- Слот освобождается только в `finally`; `force_stopping` не отдаёт слот, пока
  поток жив.
- Отменённый прогон никогда не помечается `completed`.
- Отсоединённый прогон не пишет файлы, не ходит в сеть и не получает ответов на
  подтверждения.
- Гранты выдаются на конкретный файл или конкретную папку — ровно то, что написано
  в окне подтверждения.

## Остаточные риски

| Риск | Почему остаётся | Что делать |
|---|---|---|
| **DNS-rebinding** между проверкой и соединением | `check_url` резолвит адрес, `urllib` резолвит повторно; нужен враждебный DNS с коротким TTL | закрывать исходящий трафик фаерволом; для строгой изоляции — отдельная сеть/контейнер |
| **Сторонний инструмент** исполняет свой код | обёртка проверяет только аргументы и подтверждение, но не поведение класса | включать поимённо и осознанно; не включать там, где в рабочей области лежат секреты |
| **Прогон живёт в процессе приложения** | жёсткая изоляция не сделана | запускать Studio под отдельной учётной записью, если работаете с недоверенными материалами |
| **Ключи расшифровываются в памяти** | иначе их нельзя передать провайдеру | не запускать на общей машине под общей учётной записью |
| **Сгенерированный Python-код** исполняется вне песочницы Studio | это отдельный артефакт; в нём нет встроенных инструментов, но есть модель и сеть | просматривать код перед запуском |
| **pip install из интерфейса** ставит пакет в рабочее окружение | удобство важнее строгости | ставить `crewai-tools` на этапе настройки, а не в середине работы |

## Рекомендации по эксплуатации

1. Не выставляйте порт в локальную сеть: у API нет пароля.
2. Работайте под своей учётной записью Windows — DPAPI привязан к ней.
3. Для недоверенных материалов (чужие файлы, веб-страницы, промпты) отключите
   инструменты записи и включите «Подтверждение изменений».
4. Держите `data/settings.json` и `data/.secret.key` вне репозиториев и бэкапов
   общего доступа.
5. Периодически очищайте историю запусков: в ней остаются промпты и ответы.

## Сообщить об уязвимости

Если нашли проблему, не публикуйте её в открытом issue: опишите шаги
воспроизведения в приватном сообщении владельцу репозитория. Приложите версию
(`/api/info`) и `error_id` из ответа, если ошибка уже проявлялась.


## Аккаунты и сессии

- Пароли: PBKDF2-HMAC-SHA256, 200 000 итераций, случайная соль на пользователя (`app/auth.py`).
  Это односторонний хеш, а не шифрование: исходный пароль не хранится и не восстанавливается.
- После первого входа с паролем по умолчанию аккаунт помечается `must_change`; пока пароль не сменён,
  API отвечает 403, а страницы перенаправляют на `/change-password.html`.
- Время жизни сессии задаётся в настройках (`session_ttl_hours`, по умолчанию 12 ч) и попадает в `Max-Age` cookie.
- Сессии: случайный токен в cookie `studio_session` (HttpOnly, SameSite=Lax, 7 дней); на диске хранится SHA-256 токена.
- Все `/api/*`, кроме `/api/auth/*`, требуют сессию; страницы перенаправляют на `/login`.
- `/api/auth/password` требует действующую сессию и проверяет текущий пароль.
- Попытки подбора ограничены локальным характером приложения; для сетевого доступа сервер по-прежнему
  слушает только loopback.
- `CREWAI_STUDIO_NO_AUTH=1` отключает проверку — только для автотестов.
