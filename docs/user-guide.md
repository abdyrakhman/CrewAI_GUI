# Руководство пользователя

CrewAI Studio — локальное приложение с графическим интерфейсом для сборки и запуска
команд ИИ-агентов на [CrewAI](https://crewai.com). Всё работает на вашем компьютере:
проекты, история запусков и ключи лежат в папке `data`, в интернет уходят только
запросы к выбранной модели.

## Установка и первый запуск

1. Установите **Python 3.11 или новее** (проверено на 3.12) и **Google Chrome** —
   он нужен только для браузерных тестов, не для работы.
2. Распакуйте папку проекта, например в `E:\CrewAI`.
3. Двойной щелчок по `start.bat`. Скрипт:
   - создаст виртуальное окружение `.venv`;
   - установит зависимости из `requirements.txt` (CrewAI и его зависимости);
   - запустит сервер и откроет браузер на `http://127.0.0.1:7860`.

Первый запуск занимает несколько минут: скачиваются пакеты. Следующие — секунды.

Если порт 7860 занят, приложение возьмёт следующий свободный и напишет адрес в консоли.
Запускать вручную можно так:

```bat
.venv\Scripts\python.exe run.py --port 7860
.venv\Scripts\python.exe run.py --no-browser
```

Сервер слушает только `127.0.0.1`. Запуск на другом адресе запрещён: у интерфейса нет
пароля, и выставлять его в сеть нельзя.

## Первый проект

1. Нажмите **«Новый проект»** в левой панели или выберите готовый шаблон в разделе
   **«Шаблоны»** (исследование → бриф, статья, ревью кода, разбор обращений).
2. Придумайте название и, если нужно, описание.
3. Добавьте агента и задачу — кнопки «Добавить агента» и «Добавить задачу» под
   соответствующими блоками.
4. Нажмите **«Запустить»** в правом верхнем углу.

Проект сохраняется автоматически через секунду после правки; кнопка «Сохранить»
нужна, только если хотите сохранить немедленно. Индикатор в правом верхнем углу
показывает состояние: «сохранено», «есть изменения», «сохраняю…».

## Агенты

У агента есть:

| Поле | Что значит |
|---|---|
| **Роль** | Кем является агент («Аналитик», «Архитектор»). Из библиотеки ролей можно подставить цель, опыт, характер и инструменты одной кнопкой. |
| **Цель** | Чего агент добивается в проекте. |
| **Предыстория** | Опыт и характер: чем подробнее, тем предсказуемее поведение. |
| **Модель** | Пусто — используется модель проекта/глобальная. Можно указать свою для агента. |
| **Инструменты** | Что агент умеет, кроме разговора: файлы, URL, дата и время. |
| **Делегирование** | Разрешить агенту передавать подзадачи другим агентам. |
| **Подтверждение изменений** | Включено — каждая запись файла спрашивает разрешение. Выключено — агент пишет сам. |
| **Макс. итераций** | Сколько шагов «мысль → инструмент → наблюдение» агент может сделать. По умолчанию 12. |
| **Лимит времени, с** | Жёсткий предел на работу агента. `0` — без ограничения. |
| **Рассуждения** | Дополнительный запрос к модели на каждом шаге: качественнее, но медленнее и дороже. |

## Задачи

У задачи есть описание, ожидаемый результат, исполнитель, контекст (задачи, чьи
результаты нужно учесть), формат вывода (`текст`, `markdown`, `файл`, `JSON`) и
имя файла для формата «файл» — только имя, без пути: результат всегда пишется в
рабочую область проекта.

Порядок задач в списке — порядок выполнения. В последовательном процессе задачи
идут одна за другой, в иерархическом — менеджер распределяет их сам.

## Роли

Раздел **«Роли»** — библиотека персонажей: исследователь, аналитик, редактор,
архитектор, критик, тестировщик и другие. У роли есть цель, опыт, характер и
набор инструментов.

- Выберите роль у агента (кнопка со звёздочкой рядом с полем «Роль») — цель,
  предыстория и инструменты подставятся автоматически; уведомление позволяет
  отменить действие.
- Роли можно создавать, редактировать и удалять. Кнопка «Сбросить к стандартным»
  возвращает встроенный набор (ваши роли при этом удаляются — приложение спросит
  подтверждение).

## Шаблоны

Шаблон — сохранённый каркас проекта: агенты, задачи, модель, настройки. Рабочая
область в шаблон не попадает: она принадлежит проекту, а не шаблону.

- **Свой шаблон:** кнопка «В шаблон» в проекте или «Новый шаблон» в разделе
  «Шаблоны».
- **Применить:** «Шаблоны» → выберите шаблон → создастся новый проект.
- **Редактировать:** значок карандаша открывает шаблон в конструкторе — добавьте агентов и задачи и нажмите «Сохранить шаблон». Рабочая область в шаблон не входит.
- **Пустой шаблон:** кнопка в шапке раздела создаёт шаблон без команды и сразу открывает его в конструкторе.
- **Удалить:** значок корзины на карточке шаблона.

## Рабочая область проекта

Рабочая область — папка, в которой агенты читают и пишут файлы. По умолчанию это
`data/workspaces/<id проекта>`.

- **Выбрать папку:** кнопка «Выбрать» — встроенный проводник с дисками, подпапками
  и созданием новой папки.
- **Вернуть по умолчанию:** кнопка со стрелкой рядом с полем пути.
- **Другие диски:** выберите диск в проводнике — если папка вне разрешённых, появится кнопка
  «Разрешить эту папку». Она добавляет корень в настройки, после чего папка открывается.
- **Разрешённые корни:** проводник видит домашнюю папку, папку проекта и всё, что
  перечислено в «Настройки → Доступ к папкам». Служебные каталоги (`Windows\System32`,
  `Startup`, `.ssh`, `site-packages`, `app`, `web`, `data\crews`) выбрать нельзя.

Если проект принесли копией папки `data` из другого места и в нём записана
недопустимая папка, при запуске приложение откатится на папку по умолчанию и
напишет предупреждение в журнал запуска.

**Права на папку.** При открытии папки приложение сразу проверяет чтение и запись: для папки только для чтения кнопка «Выбрать эту папку» неактивна, а сохранение такой рабочей области отклоняется с пояснением.

## Входные данные и скобки

Входные данные — поля, которые подставляются в текст задач по шаблону `{имя}`.
Например, поле `topic` подставится в описание «Исследуй {topic}».

- Поля добавляются в блоке «Входные данные» (ключ, подпись, значение по умолчанию).
- Если в тексте есть `{что-то}`, а такого поля нет, **запуск не упадёт**: скобки
  останутся в тексте как есть. В панели проверки появится предупреждение с именем
  плейсхолдера.
- Если значение нужно подставлять — добавьте поле с таким ключом.

CrewAI ищет `{имя}` даже внутри двойных скобок, поэтому «экранировать» текст
удвоением бесполезно — приложение делает это за вас.

**Запрос подтверждения у человека.** Переключатель отключён: CrewAI умеет спрашивать подтверждение только в консоли, поэтому в графическом режиме запуск на этом флаге зависал. Флаг остаётся в проекте, но при запуске игнорируется — в панели проверки будет предупреждение. В сгенерированном Python-коде он сохраняется и работает в терминале.

## Вход

При первом открытии приложение просит войти. Первый администратор создаётся автоматически:
**admin / 123admin!** — сразу смените пароль в «Настройки → Аккаунт».

- Первый вход с паролем по умолчанию открывает экран «Смените пароль»: пока пароль не сменён,
  остальные страницы и API закрыты.
- Время жизни сессии по умолчанию 12 часов; меняется в «Настройки → Аккаунт» (1 час — 7 дней).
- «Выйти» и «Выйти везде» — в настройках, карточка «Аккаунт».
- После 5 неудачных входов вход блокируется на 10 минут.
- Смена пароля — там же: текущий пароль, новый (от 8 символов), «Сменить».
- Подробно: [auth.md](auth.md) — сессии, роли, восстановление доступа.

## Запуск и наблюдение

Перед запуском приложение проверяет проект (агенты, задачи, исполнители, лимиты,
инструменты, плейсхолдеры). При ошибке запуск не начнётся, а панель покажет, что
именно исправить.

Во время запуска видно:

- таймер, число выполненных задач и расход токенов;
- карточки задач со статусом: «ожидает», «выполняется», «готово»;
- живой текст ответа модели по каждой задаче (если включена потоковая передача);
- вызовы инструментов и предупреждения;
- вкладки «Результат», «По задачам», «Журнал».

В начале журнала печатаются действующие параметры: итерации, лимит времени,
рассуждения, память, число инструментов, модель. Это первое, что стоит смотреть,
если запуск идёт не так, как ожидалось.

## Запросы доступа и подтверждения

Если агенту нужен файл за пределами рабочей области или запись при включённом
«Подтверждении изменений», выполнение **встаёт на паузу** и появляется окно:

- что именно просит агент (файл или папка);
- какой агент просит;
- «Разрешить», «Разрешить до конца запуска», «Запретить».

«До конца запуска» для записи открывает конкретный файл или папку — ровно то, что
написано в окне. Без ответа доступ закрывается через 5 минут.

Служебные каталоги (Startup, System32, `.ssh`, `site-packages`, внутренние папки
приложения) отклоняются сразу, без диалога.

## Остановка и «Отсоединить»

- **«Остановить»** — работа прекращается на ближайшем шаге. Кнопка переходит в
  «Останавливаю…», а запуск — в состояние «останавливается».
- Если модель или инструмент зависли, через 12 секунд запуск помечается
  «принудительно останавливается». Слот освободится, когда поток завершится.
- **«Отсоединить»** — освобождает слот немедленно. Отсоединённый запуск больше не
  пишет файлы (даже внутри рабочей области), не ходит в сеть и не получает ответов
  на запросы доступа.

## История и отчёты

- История листается страницами по 50 записей: внизу «Показано 1–50 из 120», кнопки «Назад/Вперёд»,
  фильтр по статусу (завершён, ошибка, остановлен).
- Срок хранения задаётся в «Настройки → История запусков»: 30/90/180 дней, год или «Хранить всегда».
  Старые запуски удаляются при следующем старте; всего хранится не больше 5000 записей.


«История запусков» хранит все запуски: проект, статус, время, длительность, токены.
Запуск можно открыть, посмотреть события, скачать отчёт `.md` или `.json` и удалить.
Историю можно очистить целиком.

Прерванные из-за перезапуска приложения запуски при старте помечаются как
незавершённые — они не висят вечно в «выполняется».

## Файлы проекта

Раздел «Файлы проекта» показывает рабочую область и результаты задач. Сюда же
можно загрузить файл, чтобы агент его прочитал. Просмотр и скачивание — только
внутри рабочей области и папки результатов.

## Настройки

- **Модель по умолчанию** — формат `провайдер/модель`, например `deepseek/deepseek-chat`.
- **API-ключи** — OpenAI, Anthropic, Gemini, OpenRouter, Groq, DeepSeek. Хранятся
  зашифрованными (Windows DPAPI) и никогда не возвращаются в браузер: интерфейс
  видит только «ключ сохранён». Кнопка «Проверить» делает один короткий запрос.
- **Ollama / LM Studio / любой OpenAI-совместимый сервер** — укажите base URL и
  модель, ключ можно оставить пустым.
- **Потоковая передача ответов** — печатать текст по мере генерации.
- **Сетевые инструменты третьих сторон** — по умолчанию выключены. Включённый
  инструмент работает вне песочницы приложения, поэтому каждый его сетевой вызов
  спрашивает разрешение.
- **Доступ к папкам** — дополнительные корни для проводника рабочей области.
- **Переменные окружения** — только `*_API_KEY`, `*_BASE_URL` и `STUDIO_*`;
  остальные отклоняются с пояснением.

## Экспорт, импорт и бэкап

- **Экспорт проекта:** в конструкторе кнопка «Экспорт» скачивает `project-<id>.json` с агентами,
  задачами, входами и настройками; рабочая область в файл не входит.
- **Импорт проекта:** кнопка «Импорт проекта» в боковой панели — выберите JSON. Создаётся новый проект
  с новым id; рабочая область сбрасывается, её нужно выбрать заново.
- **Бэкап данных:** «Настройки → Резервная копия» — ZIP с проектами, ролями, шаблонами, настройками
  и аккаунтами (логи и сессии не входят). Кнопка «с историей запусков» добавляет `runs/`.
- Ключи API в архиве остаются зашифрованными и расшифровываются только на этой машине.

## Логи и диагностика

- Логи приложения: `data/logs/app-YYYYMMDD.jsonl` (JSON Lines, ротация 10 МБ, хранение 30 дней).
- Ошибка 500 показывает `error_id` — по нему запись ищется в логе, `request_id` связывает с запросом.
- История запусков и события — в `data/runs/` и на странице запуска.
- Подробно: [logging.md](logging.md).

## Где лежат данные

| Что | Где |
|---|---|
| Проекты | `data/crews/*.json` |
| История запусков | `data/runs/*.json` + индекс `data/runs/index.jsonl` |
| Роли | `data/roles.json` |
| Свои шаблоны | `data/templates/*.json` |
| Рабочие области | `data/workspaces/<id проекта>` |
| Загруженные и созданные файлы | `data/uploads`, `data/outputs` |
| Настройки и ключи | `data/settings.json` (ключи зашифрованы) |
| Логи | `data/logs/app-ГГГГММДД.jsonl` |

Папку `data` можно копировать целиком — но на другом аккаунте Windows зашифрованные
ключи не откроются, их нужно ввести заново.
