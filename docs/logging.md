# Логирование и диагностика

## Куда пишутся логи

- `data/logs/app-YYYYMMDD.jsonl` — по файлу на день, JSON Lines, UTF-8.
- Ротация по размеру: при 10 МБ файл переименовывается в `app-YYYYMMDD.jsonl.1`.
- Хранение: 30 дней; старые файлы удаляются при старте приложения.
- Логи локальные: никуда не отправляются.

## Что внутри

- `{"kind": "request", "request_id", "method", "path", "status", "ms"}` — каждый HTTP-запрос.
- `{"kind": "error", "error_id", "request_id", "method", "path", "error", "traceback"}` — необработанные
  исключения; трассировка обрезана до 20 кадров.
- `{"kind": "event", ...}` — отдельные события приложения.
- Тела запросов и ответов не логируются.

## Секреты

- Ключи, токены и пароли вырезаются: шаблоны `sk-…`, `Bearer …`, `api_key/token/secret=…` заменяются
  на `[redacted]`, строка обрезается до 8000 символов.
- Ключи из «Настроек» в лог не попадают.
- Всё равно не публикуйте лог целиком: в тексте ошибок бывают имена файлов и фрагменты данных.

## Код ошибки (error_id)

- На внутреннюю ошибку сервер отвечает `500` с телом `{"error": "...", "error_id": "a1b2c3d4"}` и
  заголовком `X-Request-Id`.
- В интерфейсе код показывается в сообщении об ошибке.
- Найти запись:

```powershell
Select-String -Path data\logs\app-*.jsonl -Pattern '"error_id":"a1b2c3d4"'
```

- Поле `request_id` связывает ошибку с конкретным запросом в том же файле.

## Журнал в интерфейсе

GET /api/logs/recent?limit=150&errors=1 отдаёт хвост журнала (до 500 строк) для «Настройки → Диагностика».
Требуется сессия; секреты в строках уже заменены на [redacted].

## Логи запусков

- `data/runs/<id>.json` — статус, события, потоковые ответы, предупреждения, результат и расход токенов.
- `data/runs/index.jsonl` — компактная история для списка «История запусков».
- В интерфейсе: «История запусков», страница запуска с живыми событиями и отчёт `.md`.
- Предупреждения проверки проекта и ошибки задач видны в панели проверки и на странице запуска.

## Коды ответов

| Код | Что значит |
|---|---|
| 400 | неверные данные: валидация, папка, настройки |
| 401 | нет сессии — войдите |
| 403 | нет токена сессии, запрещённый путь или нужно сменить пароль |
| 404 | объект не найден |
| 409 | конфликт: запуск уже идёт, папка занята |
| 422 | некорректный код проекта или частичное сохранение |
| 429 | слишком много запросов |
| 500 | внутренняя ошибка — ищите по `error_id` |

## Очистка

При остановленном приложении можно удалить `data/logs/*` — история запусков и настройки не пострадают.
